# HomeSweet Search Load Test

HomeSweet 검색 시스템의 성능을 검증하기 위한 **부하 테스트 시나리오 모음**입니다.  
이 테스트 세트는 실제 대규모 서비스의 검색 패턴을 기반으로 설계되었으며,  
검색 API의 **평균 부하, 최대 부하, 스파이크, 장기 안정성, 사용자 행동 기반 플로우**까지 모두 측정할 수 있습니다.


---

## 테스트 목표 요약

| 시나리오 | 목적 | 목표 트래픽 |
|----------|------|--------------|
| **평균 부하 테스트** | 일반 트래픽 안정성 검증 | 350 RPS |
| **Ramp-up 테스트** | 트래픽 증가 시 병목 지점 찾기 | 300 → 10,000 RPS |
| **Spike 테스트** | 순간 트래픽 폭증 시 안정성 | 10,000 RPS |
| **Soak 테스트** | 장시간 부하에서 메모리·GC·스레드 안정성 검증 | 600 RPS |
| **Behavior Flow 테스트** | 실제 사용자 행동 기반 시나리오 검증 | VU 기반 |

---

## 검색어 선택 전략 (Zipf 분포)

검색 시스템 성능을 사실적으로 측정하기 위해  
검색어는 다음과 같은 Zipf-like 분포를 기반으로 랜덤 선택됩니다.

| 검색어 그룹 | 비율 | 설명 |
|-------------|------|------|
| 인기 검색어 Top 10 | 60% | 캐싱이 잘 되므로 빠른 요청 검증 |
| 중간 검색어 Top 50 | 30% | 일반적인 검색 요청 시나리오 |
| 롱테일 검색어 Top 200 | 10% | 느린 쿼리 검증 및 병목 탐지 |
